# 📘 Python Dictionary

## 🔹 A) Dictionary METHODS (object ke sath use hote hain)

👉 Total = 11

- clear()       → Removes all key-value pairs from the dictionary.
- copy()        → Returns a shallow copy of the dictionary.
- fromkeys()    → Creates a dictionary from given keys with same default value.
- get()         → Safely returns value of a key (no error if key missing).
- items()       → Returns all key-value pairs as view object.
- keys()        → Returns all keys of the dictionary.
- values()      → Returns all values of the dictionary.
- pop()         → Removes and returns value of specified key.
- popitem()     → Removes and returns last inserted key-value pair.
- setdefault()  → Returns value of key or inserts key with default value.
- update()      → Updates dictionary using another dictionary.

## 📘 B) Built-in FUNCTIONS used with Dictionary

👉 Ye dictionary ke methods nahi hain,

👉 Ye Python ke general functions hain jo dictionary par kaam karte hain.

- len()      → Returns total number of key-value pairs.
- type()     → Returns data type of dictionary.
- sorted()   → Returns sorted list of dictionary keys.
- min()      → Returns smallest key.
- max()      → Returns largest key.
- sum()      → Returns sum of dictionary keys (numeric keys).
- any()      → Returns True if any key is True.
- all()      → Returns True if all keys are True.
- dict()     → Creates a dictionary.

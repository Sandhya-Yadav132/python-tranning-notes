# Built-in Functions That Work With Tuples
## Information / Calculation
- len(tuple)
- min(tuple)
- max(tuple)
- sum(tuple)

## Type & Conversion
- tuple()
- list(tuple)
- set(tuple)
- sorted(tuple)

## Iteration & Checking

- enumerate(tuple)
- all(tuple)
- any(tuple)

## Tuple Operations (Very Important)
- Indexing → tuple[i]
-  indexing → tuple[-1]
- Slicing → tuple[start:end:step]
- Membership → in, not in
- Concatenation → +
- Repetition → *
